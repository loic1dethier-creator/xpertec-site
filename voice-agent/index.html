Agent Vocal IAAppuyez sur le micro pour parler

👋 Bonjour

Appuyez sur le micro et parlez naturellement. L'agent répond à voix haute et peut agir sur votre iPhone : appeler, SMS, e-mail, itinéraire, lancer un Raccourci…

Pour activer l'IA, ouvrez ⚙️ Réglages et collez votre clé API Claude.

Astuce : créez des Raccourcis Apple et dites leur nom à l'agent pour qu'il les déclenche.

Tapez pour parler · re-tapez pour arrêter

⚙️ Réglages

Obtenue sur console.anthropic.com. Stockée uniquement sur cet appareil.
Ex : « Tu es mon assistant personnel. Réponds de façon concise, car tes réponses seront lues à voix haute. »
L'agent lit ses réponses.
Relance l'écoute après chaque réponse.
🔒 Votre clé API ne quitte jamais votre iPhone : elle est gardée dans le navigateur (localStorage) et envoyée uniquement à l'API d'Anthropic. N'utilisez cette page que sur votre appareil personnel.
